## 📅 My Daily Routine

Consistency matters more than trying to do everything in one day. My routine is designed to balance technical learning, physical activity, and personal development.

| Activity | Daily Goal |
|---|---|
| 📚 Academic or technical study | Review concepts and take notes |
| 💻 Coding practice | Solve a programming exercise |
| ⚙️ Engineering learning | Study a concept or solve a numerical problem |
| 🏃 Physical exercise | Complete a suitable workout or walk |
| 📝 Documentation | Record progress and lessons learned |
| 🎯 Planning | Set priorities for the next day |

These activities are flexible. The purpose is to build sustainable habits rather than follow a perfect schedule.

- Explore AI-assisted engineering solutions.
